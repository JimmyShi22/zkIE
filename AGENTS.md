# Agent Instructions

Read `CLAUDE.md` at the repository root and follow it in full.

`CLAUDE.md` is the single source of project conventions for every agent
working in this repository: entry points, directory layout, build and test
methods, hard development rules, and workflow red lines. When this file and
`CLAUDE.md` disagree on anything, `CLAUDE.md` wins.

Also read `.dev-method/DEV_METHOD.md` at the repository root before starting
any work item. It is confidential, gitignored, local only, never committed and
never pushed. If the file is absent, ignore this instruction and follow
`CLAUDE.md` alone.

No work item starts before the Tech Lead has confirmed its approach with the
technical expert through the local channel kept outside the repository; items
without that confirmation stay parked.
